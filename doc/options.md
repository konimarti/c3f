# Options

Every option of c3f in one table: what it does, its values and default, and a before / after example.
Values go into `.editorconfig` under `[*.{c3,c3i}]` (the nearest file wins) or on the command line with
`--set key=value`. The man page ([`c3f.1.scd`](../c3f.1.scd), `man c3f`) and the [README](../README.md) say more.

Every After cell is real output: c3f was run on the Before text with only the setting named in the
description (plus `max_line_length` and `c3f_line_breaks` where the effect is a wrapped line).
Legend: `→` a tab, `⏎` a line end (shown where blank lines
or the end of the file matter), `␍⏎` a CRLF line end; several lines are written under one another.

| Option | Description | Before | After |
|---|---|---|---|
| `c3f_style` | A preset, applied before the other options, which override it. `stdlib` (**default**): the style of the C3 standard library. `knr`: K&R braces, also for functions, and `} else {`. `strict`: `stdlib` with the spacing made uniform where the standard library itself varies (`Foo* p`, padded initializer braces, tight slices) and sorted imports. Example: `--set c3f_style=knr`. | <pre>fn void f()<br>{<br>→x();<br>}</pre> | <pre>fn void f() {<br>→x();<br>}</pre> |
| `indent_style` | Indent with `tab` (**default**) or `space`. Example: `--set indent_style=space`. | <pre>if (x)<br>{<br>→a();<br>}</pre> | <pre>if (x)<br>{<br>    a();<br>}</pre> |
| `indent_size` | The width of one level with spaces: 1 to 16, or `tab` (the value of `tab_width`). **default** `4`. Example: `--set indent_style=space --set indent_size=2`. | <pre>if (x)<br>{<br>→a();<br>}</pre> | <pre>if (x)<br>{<br>  a();<br>}</pre> |
| `tab_width` | The width of a tab, for aligning and for the line length: 1 to 16. **default** `4`; it follows `indent_size` when that is set and this is not. Example: `--set tab_width=8 --set max_line_length=20 --set c3f_line_breaks=wrap`: the tab counts 8 columns, so the call wraps. | <pre>fn void f()<br>{<br>→foo(aaaa, bbbb, cc);<br>}</pre> | <pre>fn void f()<br>{<br>→foo(aaaa,<br>→→bbbb,<br>→→cc);<br>}</pre> |
| `end_of_line` | The line ending: `keep` (**default**, the file's own), `lf` or `crlf`. Example: `--set end_of_line=crlf`. | <pre>int x;⏎<br>int y;⏎</pre> | <pre>int x;␍⏎<br>int y;␍⏎</pre> |
| `insert_final_newline` | Add a line break at the end of a file that has none: `true` (**default**) or `false` (a break that is there stays either way). Example: `--set insert_final_newline=false` leaves the file without one (the default would add `⏎`). | `int x;` | `int x;` |
| `max_line_length` | The column limit used by wrapping and alignment: `off` (**default**), or 1 to 10000. Without it `c3f_line_breaks` has no effect. Example: `--set max_line_length=40 --set c3f_line_breaks=wrap`. | `foo(aaaaaaaaaaa, bbbbbbbbbbbb, ccccccccccccc, dddddddddddd);` | <pre>foo(aaaaaaaaaaa, bbbbbbbbbbbb,<br>→ccccccccccccc, dddddddddddd);</pre> |
| `c3f_line_breaks` | What c3f may do with line breaks; it needs a `max_line_length`. `keep` (**default**) never moves them. `wrap` breaks the statements that have a line over the limit. `wrap_rewrite` is `wrap` and also splits a long string literal into joined pieces and puts braces around a too long braceless body (these add tokens). `reflow` also lays out again every statement that spans several lines, so a break made by hand is joined if the statement fits. Example: `--set c3f_line_breaks=reflow --set max_line_length=40`. | <pre>foo(a,<br>→b);</pre> | `foo(a, b);` |
| `c3f_brace_style` | Where the opening brace goes: `allman` (**default**, on its own line), `knr` (on the line of the header) or `linux` (`knr`, but the braces of functions on their own line). Example: `--set c3f_brace_style=knr`. | <pre>if (x)<br>{<br>→a();<br>}</pre> | <pre>if (x) {<br>→a();<br>}</pre> |
| `c3f_else_style` | Where `else` goes: `follow` (**default**) the brace style, `own_line` or `same_line` (after the `}`). Example: `--set c3f_else_style=own_line --set c3f_brace_style=knr`. | <pre>if (x) {<br>→a();<br>} else {<br>→b();<br>}</pre> | <pre>if (x) {<br>→a();<br>}<br>else {<br>→b();<br>}</pre> |
| `c3f_while_style` | Where the `while` of a `do` loop goes: `keep` (**default**, as written), `own_line` or `same_line` (after the `}`). Example: `--set c3f_while_style=same_line`. | <pre>do<br>{<br>→x();<br>}<br>while (y);</pre> | <pre>do<br>{<br>→x();<br>} while (y);</pre> |
| `c3f_one_line_blocks` | A block written on one line: `keep` (**default**) or `expand`, which puts its statements (and the members of a one-line `struct`, `enum`, ...) on lines of their own. Example: `--set c3f_one_line_blocks=expand`. | `if (x) { a(); b(); }` | <pre>if (x)<br>{<br>→a();<br>→b();<br>}</pre> |
| `c3f_case_indent` | Indent `case` under `switch`: `indent` (**default**), or `flush` (the same column). Example: `--set c3f_case_indent=flush`. | <pre>switch (x)<br>{<br>→case 1:<br>→→a();<br>}</pre> | <pre>switch (x)<br>{<br>case 1:<br>→a();<br>}</pre> |
| `c3f_compile_time_indent` | The contents of `$if`, `$switch` and `$foreach` blocks: `keep` (**default**, as written), `indent` or `flush` (at the level of the directive). Example: `--set c3f_compile_time_indent=indent`. | <pre>$if X:<br>foo();<br>$endif</pre> | <pre>$if X:<br>→foo();<br>$endif</pre> |
| `c3f_continuation` | How the lines of a broken statement are continued: `keep` (**default**, as written), `indent` (one more level) or `align` (under the opening bracket). Example: `--set c3f_continuation=align`. | <pre>foo(a,<br>→b);</pre> | <pre>foo(a,<br>    b);</pre> |
| `c3f_spacing` | Where the standard library writes both forms (about 0.2 % of its spacing): `stdlib` (**default**) keeps what was written, `strict` always writes the more common one. Example: `--set c3f_spacing=strict`. | `int[] a = {1, 2};` | `int[] a = { 1, 2 };` |
| `c3f_space_after_cast` | A space after a cast: `false` (**default**) `(int)x`, or `true` `(int) x`. Example: `--set c3f_space_after_cast=true`. | `x = (int)y;` | `x = (int) y;` |
| `c3f_pointer_style` | Write `Foo* p` (`type`) or `Foo *p` (`name`); `keep` (**default**) leaves it as written. Example: `--set c3f_pointer_style=type`. | `Foo *p;` | `Foo* p;` |
| `c3f_space_inside_brackets` | Spaces inside `[ ]`: `keep` (**default**), `false` (`a[i]`) or `true` (`a[ i ]`). Parentheses are not touched. Example: `--set c3f_space_inside_brackets=true`. | `a[i] = 1;` | `a[ i ] = 1;` |
| `c3f_space_inside_braces` | Spaces inside the braces of an initializer list: `keep` (**default**; with `c3f_spacing=strict` they are padded), `false` (`{1, 2}`) or `true` (`{ 1, 2 }`). Example: `--set c3f_space_inside_braces=true`. | `int[] a = {1, 2};` | `int[] a = { 1, 2 };` |
| `c3f_max_blank_lines` | More blank lines in a row are cut to this number: 0 to 100, **default** `2`. Example: `--set c3f_max_blank_lines=1`. | <pre>a;⏎<br>⏎<br>⏎<br>⏎<br>b;⏎</pre> | <pre>a;⏎<br>⏎<br>b;⏎</pre> |
| `c3f_trim_block_blanks` | Remove the blank lines after an opening and before a closing brace: `true` (**default**) or `false`. Example: `--set c3f_trim_block_blanks=false` keeps them. | <pre>if (x)⏎<br>{⏎<br>⏎<br>→a();⏎<br>⏎<br>}⏎</pre> | <pre>if (x)⏎<br>{⏎<br>⏎<br>→a();⏎<br>⏎<br>}⏎</pre> |
| `c3f_blank_lines_between_decls` | `keep` (**default**) or `1`, which puts exactly one blank line between declarations. Example: `--set c3f_blank_lines_between_decls=1`. | <pre>fn void a() {}⏎<br>fn void b() {}⏎</pre> | <pre>fn void a() {}⏎<br>⏎<br>fn void b() {}⏎</pre> |
| `c3f_align` | Align the names, `=` and `=>` of consecutive lines: `keep` (**default**) leaves the alignment as written, `decls` aligns, `off` removes it. Example: `--set c3f_align=decls`. | <pre>fn void f()<br>{<br>→int a = 1;<br>→double bbb = 2;<br>}</pre> | <pre>fn void f()<br>{<br>→int    a = 1;<br>→double bbb = 2;<br>}</pre> |
| `c3f_align_comments` | The same for trailing comments: `keep` (**default**), `always` or `off`. The blanks at the end of a `//` comment are always removed. Example: `--set c3f_align_comments=always`. | <pre>a(); // x<br>bbb(); // y</pre> | <pre>a();   // x<br>bbb(); // y</pre> |
| `c3f_trailing_comment_spaces` | The spaces before a trailing `//` comment: `keep` (**default**), or 1 to 16. Example: `--set c3f_trailing_comment_spaces=1`. | `a();     // x` | `a(); // x` |
| `c3f_magic_comma` | A trailing comma keeps one item per line when wrapping: `true` (**default**) or `false`. Example: `--set c3f_magic_comma=false --set c3f_line_breaks=reflow --set max_line_length=40` leaves `foo(a, b,);` on one line (with the default it is written one item per line). | `foo(a, b,);` | `foo(a, b,);` |
| `c3f_wrap_lists` | How a list that has to wrap is laid out (arguments, parameters, initializer elements; at least one comma between the brackets): `fill` (**default**) puts as many items on a line as fit, `one_per_line` puts each item and the closing bracket on a line of its own. No comma is added; a list that fits stays on its line. Needs `c3f_line_breaks` other than `keep`. Example: `--set c3f_wrap_lists=one_per_line --set c3f_line_breaks=wrap --set max_line_length=60`. | `foo(aaaaaaaaaaa, bbbbbbbbbbbb, ccccccccccccc, dddddddddddd, eeeeeeeeeee);` | <pre>foo(<br>→aaaaaaaaaaa,<br>→bbbbbbbbbbbb,<br>→ccccccccccccc,<br>→dddddddddddd,<br>→eeeeeeeeeee<br>);</pre> |
| `c3f_soft_max_line_length` | A second, soft limit for wrapping: every column past it costs `c3f_wrap_cost_soft`, so a line is broken earlier than `max_line_length` if that is cheaper. 0 to 10000, **default** `0` (not a switch: the limit is column 0, every column costs the same and the breaks stay where `max_line_length` puts them). Example: `--set c3f_soft_max_line_length=20 --set c3f_wrap_cost_soft=1 --set c3f_line_breaks=reflow --set max_line_length=60`. | `foo(aaaa, bbbb, cccc, dddd, eeee);` | <pre>foo(aaaa, bbbb, cccc,<br>→dddd, eeee);</pre> |
| `c3f_wrap_cost_hard` | The cost of a column past `max_line_length`: a number, 0 or more, **default** `100`. Example: `--set c3f_wrap_cost_hard=0 --set c3f_line_breaks=wrap --set max_line_length=20`: a long line costs nothing, so it is not wrapped. | `x = aaaa + bbbb + cccc + dddd + eeee;` | `x = aaaa + bbbb + cccc + dddd + eeee;` |
| `c3f_wrap_cost_soft` | The cost of a column past `c3f_soft_max_line_length`: a number, 0 or more, **default** `0.05`. Example: the one of `c3f_soft_max_line_length` (`--set c3f_wrap_cost_soft=1 --set c3f_soft_max_line_length=20 --set c3f_line_breaks=reflow --set max_line_length=60`). | `foo(aaaa, bbbb, cccc, dddd, eeee);` | <pre>foo(aaaa, bbbb, cccc,<br>→dddd, eeee);</pre> |
| `c3f_wrap_cost_break` | The cost of a line break: a number, 0 or more, **default** `2`. Example: `--set c3f_wrap_cost_break=100 --set c3f_line_breaks=wrap --set max_line_length=20`: breaks are dear, so the statement is broken once, not twice (the default breaks before `+ bbbb` as well). | `x = aaaa + bbbb + cccc + dddd + eeee;` | <pre>x = aaaa + bbbb + cccc<br>→+ dddd + eeee;</pre> |
| `c3f_wrap_max_tokens` | Statements of more tokens are not wrapped: 0 to 10000, **default** `2000`. Example: `--set c3f_wrap_max_tokens=5 --set c3f_line_breaks=wrap --set max_line_length=20`: the call has 13 tokens and stays as it is. | `foo(aaaa, bbbb, cccc, dddd, eeee);` | `foo(aaaa, bbbb, cccc, dddd, eeee);` |
| `c3f_sort_imports` | Reorder imports: `off` (**default**), `lines` (the statements of a run), `lists` (the modules inside one statement), `all` (both) or `split` (also one module per statement). The `strict` style uses `all`. Example: `--set c3f_sort_imports=all`. | <pre>import std::math, std::io;<br>import std::core;</pre> | <pre>import std::core;<br>import std::io, std::math;</pre> |
